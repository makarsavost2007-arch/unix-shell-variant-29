# Эмулятор UNIX-оболочки · вариант 29

Практическая работа по конфигурационному управлению, УНБО-04-25.
Эмулятор загружает виртуальные файлы из XML в память. Каждый запуск начинает новую сессию.
Условие варианта находится в [сборнике](docs/УНБО-04-25-1.pdf) на страницах 92–94.

## Запуск в VS Code

Откройте папку проекта и выберите «Терминал → Создать терминал».
На macOS с Ruby 2.6, REXML и Minitest сборка не требуется.

```sh
./run.sh --vfs examples/deep.xml
```

Введите `tree`, затем `du /`. В примере два файла занимают суммарно 9 байт.
Попробуйте `mv notes.txt course`, затем `ls course`. Завершите сеанс командой `exit`.

## Команды

| Команда | Действие |
| --- | --- |
| `pwd` | Показать текущий путь |
| `ls [путь]` | Вывести имена в каталоге по алфавиту или имя указанного файла |
| `cd [каталог]` | Перейти в каталог, без аргумента — в корень |
| `tree [путь]` | Показать дерево от указанного пути или текущего каталога |
| `du [путь]` | Вывести размер содержимого в байтах, включая всё поддерево |
| `mv откуда куда` | Переименовать или перенести в существующий каталог. Занятое имя вызывает ошибку |
| `rm путь` | Удалить файл |
| `rm -r путь` | Удалить поддерево. Корень, текущий каталог и его предки защищены |
| `exit` | Завершить работу |

Пути могут начинаться от корня или от текущего каталога. Поддерживаются `.` и `..`.
Парсер делит ввод по пробельным символам. Используйте имена без пробелов.

## Параметры и файлы

- `--vfs PATH` загружает XML. По умолчанию создаётся пустой корень.
- `--log PATH` дописывает строки CSV с пользователем, временем ISO 8601 и введённой командой.
- `--script PATH` выполняет команды построчно с выводом приглашения.
  Первая ошибка завершает процесс с кодом 1. После последней успешной строки открывается диалог, если не было `exit`.
- `--config PATH` читает YAML с ключами `vfs`, `log`, `script`.
  Пути YAML отсчитываются от каталога конфигурации, пути CLI — от места запуска. CLI имеет приоритет.

Корневой элемент XML — `vfs`. Элемент `dir` содержит дочерние элементы, `file` — данные в Base64.
Оба имеют атрибут `name`. Примеры — `examples/minimal.xml`, `files.xml`, `deep.xml`.

## Проверка

```sh
ruby -Itests -e 'Dir["tests/*_test.rb"].sort.each { |f| load f }'
./examples/check-cli.sh
./examples/check-error.sh
./run.sh --vfs examples/deep.xml --script examples/read.txt
./run.sh --vfs examples/deep.xml --script examples/change.txt
```

Два последних сценария завершаются намеренной ошибкой обращения к отсутствующему пути.
Скрипты ОС проверяют три образа VFS, четыре настройки CLI и остановку на первой ошибке.
